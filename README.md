Modern Calculator

Experience a modern, smooth, and intuitive calculator for Windows, redesigned to offer a familiar feel, a lightweight interface, and optimized performance!

Version: 1.0.0.2
Platform: Windows
Framework: .NET 10.0
Programming Languages: C#, XAML
External Library: WPF-UI

1. Introduction:

Modern Calculator is built entirely using Windows Presentation Foundation (WPF). This version (1.X) features a cutting-edge interface inspired by modern Windows design language, making daily calculations faster and more enjoyable.

2. Key Features:

- Native Windows Interface: Standardized design that integrates seamlessly with the Windows operating system.

- Optimized Performance: Smooth operation and rapid startup thanks to an optimized executable file.

- Multi-mode Support: Easily switch between basic and advanced calculation modes.

- User-friendly Experience: Suitable for all types of users, from students to office professionals.

3. Download & Installation:

- You can download the latest installation package directly from the "Code" section of this repository by following these steps:

+ Navigate to the "Code" section on the right-hand side.

+ Download the `Installer.zip` file to get the latest version!

+ Extract the files and run `setup.exe` to install the application on your computer.
