Modern Calculator

Experience a modern, smooth, and intuitive calculation tool on Windows, redesigned to offer a familiar, lightweight, and highly optimized experience!

Version: 1.0.0.1
Platform: Windows
Framework: .NET 10.0
External Library: WPF-UI

1. Introduction:

Modern Calculator is built entirely using Windows Presentation Foundation. Version 1.0.0.1 features a cutting-edge interface inspired by modern Windows design language, making daily calculations faster and more enjoyable.

2. Key Features:

- Native Windows Interface: Standardized design that integrates perfectly with the Windows operating system.

- Optimized Performance: Runs smoothly and launches quickly thanks to an optimized executable.

- Multi-mode Support: Easily switch between basic and advanced calculation modes.

- User-friendly Experience: Suitable for all users, from students to office professionals.

3. Download & Installation:

- You can download the latest installation package directly from the "Code" section of this repository by following these steps:

+ Navigate to the "Code" section on the right-hand side.

+ Download the zip file or the latest installation package!

+ Extract the files and run `setup.exe` to install the application on your computer.
